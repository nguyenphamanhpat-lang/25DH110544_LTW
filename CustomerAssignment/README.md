# Customer Assignment - MyStoreCustomer
Project ASP.NET MVC5, .NET Framework 4.8, EF6, độc lập với project gốc.
Mở MyStoreCustomer.sln, restore NuGet, chạy database/MyStoreCustomer.sql, sau đó chạy bằng Visual Studio 2022.
Demo: customer01 / 123456.
Chức năng: đăng nhập/đăng ký, lịch sử đơn, tìm kiếm mã đơn/tên sản phẩm, lọc trạng thái, xem thêm, mua lại, xem chi tiết.
